# RECRIAR - adaptação da parte de banco

O projeto está em `RECRIAR-CSHARP-sandbox`. O nome dessa pasta veio do pacote do grupo; a branch de destino do novo repositório é `main`.

Abra a solução `Recriar.sln` dessa pasta no Visual Studio. A instalação do banco, a configuração da conexão e as limitações estão em `RECRIAR-CSHARP-sandbox/docs/database/README.md`.

A entrega de BD contém 11 tabelas, um script completo, consultas separadas, MER, DER e EER. Usa um único banco, sem views ou transações. As classes da integração foram adaptadas para os getters, setters e assinaturas da nova versão do grupo.

Não envie `conexao.txt` ao GitHub: ele contém seu acesso local.
